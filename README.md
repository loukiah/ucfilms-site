# ucfilms.de

Website of undercurrent films. Built with Eleventy, published by GitHub Pages, edited in Pages CMS.

## Editing content
Sign in at https://app.pagescms.org with GitHub and open this repository.
- **Projects**: add, reorder (Position), hide (Published), choose what's on the home page.
- **Site texts**: home tagline, studio sentence, About text, logos, behind-the-scenes photos.
- **Team**: names, roles, portraits, bios.

Saving publishes the site automatically in about a minute.

## Video
- Full films: paste a YouTube, Vimeo or Bunny Stream link.
- Moving thumbnails: upload a silent 6–12 s MP4 (under ~20 MB), or paste a direct video link plus a start time.
- DaVinci export for a thumbnail clip: H.264, 1280×720, 25 fps, quality ~8 Mbit/s, audio off.

## Developing
```
npm install
npm start    # local preview at http://localhost:8080
npm run build
```
